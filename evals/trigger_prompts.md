# 触发评测：模型什么时候该画图

每次修改 `src/chemcard/descriptions.py` 后，在新对话里逐条测试，记录模型是否调用了工具、调用了几次。
是否调用由模型决定，结果不固定，每条至少测 2 次。

目标：「应画」的命中率高，「不应画」的误触率低。

## 穿插评测：图是否紧跟对应的文字

| # | 问题 | 期望 |
|---|---|---|
| M1 | 为什么 TBS 比 TMS 稳定？ | 画 TMS → 讲 TMS → 画 TBS → 讲 TBS，不要两张图连在一起 |
| M2 | （附图）讲解一下这个机理：托品酮的 Robinson 合成 | 每步一次 show_reaction_step，图下紧跟这一步的讲解 |
| M3 | 讲一下 SN1 反应的机理 | 2–3 步，每步一张 A + B → C |
| M4 | 讲一下 Fischer 酯化的机理 | 每步一张，质子转移可合并 |

## 高亮与点选

| # | 操作 | 期望 |
|---|---|---|
| H1 | 问「阿司匹林哪部分会水解？」 | 画阿司匹林并把酯基高亮，讲解只谈被高亮的部分 |
| H2 | 问「丙氨酸的哪个原子是碱性的？」 | 用原子映射号高亮氨基 N |
| H3 | 在卡片上选中咖啡因的 N9，点「提问」，再问「它为什么能被质子化？」 | 模型复述选中的原子，回答时用相同编号高亮 |
| H4 | 只选中原子、不点提问，直接在输入框问「这个原子是什么杂化？」 | 若宿主支持 update-model-context，模型知道「这个原子」指哪里 |
